# Phase 2: Linux Operations and Automation

## Objective

Phase 2 develops Linux operations skills across a small three-server lab. The focus moves from administering one machine to operating, troubleshooting, and automating connected systems.

## Lab Infrastructure

| Host | Role |
|---|---|
| `bio-lab` (`ubuntu-lab-1`) | Primary web and networking server |
| `ubuntu-lab-2` | Secondary server for remote administration and file transfer |
| `ubuntu-monitor` | Operations workstation for monitoring and incident response |

## Documentation Pattern

Each build should contain:

- A README describing the objective and acceptance criteria

- A final report with findings, problems, and lessons learned
