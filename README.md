# Linux Mastery

This repository documents my Linux administration and system engineering learning journey through practical labs, evidence, and project reports.

## Learning Phases

### Phase 1: Linux Fundamentals

The foundation phase covers users and groups, permissions, file operations, Nginx, SSH, logs, and basic troubleshooting.

Project location:

```text
Linux_Fundamentals_Capstone/
```

### Phase 2: Linux Operations and Automation

The operations phase expands the lab from one server to a three-server environment and develops networking, remote administration, automation, storage, logging, and incident response skills.

Project location:

```text
Phase_2_Linux_Operations_Automation/
```

The current Phase 2 build is:

New build directories will be added only when each part of Phase 2 begins. Each build can contain its own README, lab instructions, command evidence, reports, screenshots, and lessons learned. This keeps the work structured without splitting one phase across unrelated root-level folders.
